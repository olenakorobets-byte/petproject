## Button Mapping

The Figma `Button` component set contains these variants:

- Variants: `Default`, `Secondary`, `Destructive`, `Outline`, `Ghost`, `Link`
- States: `Default`, `Focus`, `Hover`, `Disabled`, `Loading`, `Pressed`
- Sizes: `default`, `icon`, `sm`, `lg`

The matching React component supports:

- `variant`: `default`, `secondary`, `destructive`, `outline`, `ghost`, `link`
- `size`: `default`, `sm`, `lg`, `icon`
- native button props such as `disabled`

## Additional Component Notes

Avatar components map to `avatar.tsx`. Figma represents image and fallback avatar types with size tokens `12`, `10`, `8`, `6`, and `5`; the code exports `Avatar`, `AvatarImage`, `AvatarFallback`, `AvatarBadge`, `AvatarGroup`, and `AvatarGroupCount`.

Badge components map to `badge.tsx`. Figma has `Default`, `Secondary`, `Outline`, `Destructive`, and `Verified`; the code supports `default`, `secondary`, `outline`, `destructive`, `ghost`, and `link`, so `Verified` needs either a custom class or a future code variant.

Breadcrumb components map to `breadcrumb.tsx`. Figma item variants correspond to composition with `BreadcrumbItem`, `BreadcrumbLink`, `BreadcrumbPage`, `BreadcrumbEllipsis`, and dropdown menu components.

Calendar nodes map to `calendar.tsx` except the time preset item, which is a preset button pattern and maps to `button.tsx`. Calendar arrow and dropdown items are internal calendar/navigation patterns rather than separately exported primitives.

Card example content and footer nodes map to `CardContent` and `CardFooter`; their inner login, text, badge, and button layouts are composed from other primitives.

Carousel arrow buttons map to `CarouselPrevious` and `CarouselNext`; carousel orientation is represented by the `orientation` prop on `Carousel`.

Combobox command menu nodes are composite examples built from `ComboboxContent`, `ComboboxList`, `ComboboxItem`, and, for multiselect, `ComboboxChips`.

ContextMenu item nodes map to the relevant exports from `context-menu.tsx`, including `ContextMenuItem`, `ContextMenuSubTrigger`, `ContextMenuLabel`, and `ContextMenuSeparator`.
